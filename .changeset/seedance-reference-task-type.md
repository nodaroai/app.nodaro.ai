Seedance 2.5 reference task type (`@nodaro/shared/models`): `SEEDANCE_REFERENCE_TASK_TYPES` (`auto`, `reference`, `edit`, `extend`) names what a request's reference media is for, so the model no longer has to guess it from the prompt. `supportsReferenceTaskType(provider)` reads the new catalog capability `referenceTaskTypes` (on `seedance-2-5`), and `listedSeedanceTaskType(provider, value)` returns the value only when that model's list holds it (exact match), else `undefined`. `resolveSeedanceTaskType(facts)` decides in one place whether a request declares one and what that forces: `edit` (every reference video measured and 4–30 s, `SEEDANCE_EDIT_REF_VIDEO_SEC`) runs at `"adaptive"` and Auto length, `extend` at `"adaptive"` with a fixed length (Auto becomes the model's default), and `reference` changes nothing. A draft, a request without the media a type needs, or any other value declares nothing and changes nothing. Each change comes back as a `ModelInputAdjustment` with a readable reason; a ratio that already runs at the one a type forces is not a change (`"Auto"` with a reference video runs at `"adaptive"`). `isVideoAutoAspectToken(value)` and `videoAutoAspectRunsAt(model, hasVisualInput)` (`@nodaro/shared/model-catalog`) state that one rule: the video request's `"Auto"` ratio runs at `"adaptive"` when there is a frame or reference media to match and the model lists `"adaptive"`, and at the provider's fixed default otherwise. `SEEDANCE_VIDEO_EDIT_TASK_TYPE` (`"edit"`) is the task type a purpose-built Seedance video edit requests beside `SEEDANCE_VIDEO_EDIT_SHAPE`, which is unchanged. `seedanceTaskTypeFitsMedia(type, { imageCount, videoCount, audioCount })` (type `SeedanceReferenceMediaCount`) is the one rule for the reference media each declared type needs: `reference` takes any reference media, `edit` and `extend` need a reference video; start and end frames are not reference media.

`@nodaro/sdk`: `GenerateVideoParams` and `TextToVideoParams` take `referenceTaskType?: "auto" | "reference" | "edit" | "extend"`, sent as-is on `nodes.run("generate-video" | "text-to-video", …)`, `runAndWait` and `quote`. Only `seedance-2-5` reads it: `edit` takes the reference video's own shape and length when every reference video is 4 to 30 seconds long, `extend` continues it and the platform does not join the source clip to the result, `reference` keeps your ratio and length, and `auto` (the default) leaves the choice to the model. `ModelSummary.referenceTaskTypes?: Array<"reference" | "edit" | "extend">` (from `models.list()`) lists the values a model takes; it is present on `seedance-2-5` only.

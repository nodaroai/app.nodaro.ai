New `client.surface.availability()` (`GET /v1/surface/availability`, also published as `@nodaro/sdk/surface`): what the deployment offers the caller. That means the node types and models it does not offer and the Web Scrape sources it withdraws, and now every world of the shared site header with whether the caller is offered it (`worlds: [{ id, enabled }]`, in the deployment's display order). A world is enabled when the deployment lets it through and every node type it runs is available to the caller. Types: `SurfaceAvailability`, `SurfaceAvailabilityWorld`.

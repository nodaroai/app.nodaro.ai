A new KIE video model in the catalog: **PixVerse V6 Max** (`pixverse-v6-max`), made by PixVerse — a new maker, `pixverse` in `MODEL_MAKERS`.

- Catalog entry `pixverse-v6-max`: one id over two provider endpoints, chosen by what is connected. A start frame runs image-to-video, where the image is the exact first frame and the clip takes its shape (no aspect ratio is sent); no image runs text-to-video at one of eight aspect ratios (`16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `2:3`, `3:2`, `21:9`). Both modes, 1–15 s (default 5), `360p` / `540p` / `720p` / `1080p` with a declared default of `720p` (`defaultResolution`, `unlistedResolutionRendersAs`, `PRICING_DEFAULT_RESOLUTION`), a seed, no end frame, no reference images, videos or audio, prompts up to 5,000 characters. Feature `audio` only. Free credits treat it like any other video model: within their limits (360p, 1–4 s).
- Native audio behind its own switch: `VIDEO_AUDIO_CAPABILITY["pixverse-v6-max"]` is `{ mode: "ambient", field: "generateAudioSwitch", affectsCost: true, defaultOn: true, readsGenerateAudio: true }`. `VideoAudioCapability` gains the field value `"generateAudioSwitch"` (written as `generate_audio_switch`) and the flag `readsGenerateAudio`. The model joins `AUDIO_ADDON_PROVIDERS`; its audio is the request's `sound`, else `generateAudio`, and a request that names neither renders and bills audio on.
- One reading of a request's audio fields: new `videoAudioIntent(provider, { sound, generateAudio })` and `videoAudioPricedOn(provider, request)` (type `VideoAudioRequest`). `applyVideoAudioToggle` and `buildVideoCreditModelIdentifier` both resolve through it. Kling keeps reading `sound` alone and every other model `sound`, else `generateAudio`, as before.
- Credit identifiers: `pixverse-v6-max:<N>s:<quality>` per second without audio and `pixverse-v6-max:<N>s:<quality>:audio` with it. `buildVideoCreditModelIdentifier`'s audio argument now also takes the whole audio request (`{ sound, generateAudio }`; a boolean is `sound`, as before), and it appends `:audio` after every other dimension; the Kling ids it builds (`kling-3.0:10s:audio`, `kling:5s:audio`) are unchanged. `videoGenerationCreditId` takes `generateAudio`. Any other quality bills (and is sent) as 720p. `VIDEO_VARIABLE_PRICING` gains the value `"duration+resolution+audio"`.
- Generate Video Pro: the catalog field `gvpWithoutReferences` admits a model that takes a start frame but no reference images; `pixverse-v6-max` sets it and joins `GVP_SUPPORTED_PROVIDERS` (keyframes only, no end anchor). `resolveGvpAnchorWire(choice, provider?)` takes the model: a stored `"reference"` on such a model resolves to Auto.
- New exports `PIXVERSE_V6_MAX_PROVIDER`, `isPixverseV6MaxProvider()`, `PIXVERSE_V6_MAX_DEFAULT_QUALITY` and `normalizePixverseV6MaxQuality()` (folds case, collapses anything else to 720p — the runner sends and the credit identifier bills through it).
- `uiResolutionFill` / `uiDurationFill` return 720p / 5 s for `pixverse-v6-max`; `QUALITY_MAP` maps low / mid / high to 540p / 720p / 1080p.

Nemotron 3.5 Transcribe, a fourth transcription engine: `nemotron-3-5-transcribe` joins `TRANSCRIBE_PROVIDERS` and `TRANSCRIBE_LANES` (at the end: `elevenlabs-stt` stays first and the node default, `whisper` the route default) and the catalog (maker `nvidia`, a new `MODEL_MAKERS` entry; mode `stt`; priced per started minute of the file through a row that prices four minutes). It transcribes 40 languages, detected automatically, returns word timings with a speaker per word on request, and is the one engine that translates. `TRANSCRIBE_PROVIDER_CAPABILITIES` rows gain `translation`. New from `@nodaro/shared/models`: `TRANSCRIBE_TARGET_LANGUAGES` and `TranscribeTargetLanguage` (the languages it translates into, to or from English), `transcribeProvidersWithTranslation`, `transcribeLaneSupportsTranslation`, and `CAPTION_TRANSCRIBE_LANES` / `CaptionTranscribeLane` (the three lanes Add Captions transcribes on, unchanged). From `@nodaro/shared/nodes`: `transcribeTranslationRefusal` (the refusal every run surface gives: a translation on another engine, into a language it does not take, or beside word timings) and `transcribeTargetLanguageOf`; `transcribeWordTimestampsRefusal` takes an optional target language, and `findWordlessTranscriptFeeds` treats a translating node as wordless. From `@nodaro/shared/credits`: `NEMOTRON_TRANSCRIBE_ID`, `NEMOTRON_TRANSCRIBE_PRICING`, `nemotronTranscribeStartedMinutes`, `nemotronTranscribeCreditId`, `nemotronTranscribeQuoteCreditId`, `parseNemotronTranscribeCreditId` and `nemotronTranscribeBaseCredits`.

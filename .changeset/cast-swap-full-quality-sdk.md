Cast Swap (`client.castSwap`) finishes a draft at Full Quality: `fullQualityEstimate(jobId)` (`POST /v1/cast-swap/:jobId/full-quality/estimate`, free) returns `CastSwapFullQualityEstimate` (`{ totalCredits, breakdown: { castSwap, seedanceHd }, availableUntil }`; `seedanceHd` is 0 when an earlier try's 1080p render is reused), and `fullQuality(jobId, { sessionId? })` (`POST /v1/cast-swap/:jobId/full-quality`, spends credits) re-renders the draft's take at 1080p as a new job, answering `{ jobId }`, or `{ jobId, existing: true }` when this draft's Full Quality is already running or done. `jobId` is a finished draft run (a Cast Swap or trend run made as a draft), within 7 days of completing. Refusal codes are typed as `CastSwapFullQualityRefusalCode` (`unauthorized`, `not_found`, `not_completed`, `not_a_draft`, `draft_expired`, `full_quality_pending`, `full_quality_unavailable`, `insufficient_credits` and the workspace caps, `job_blocked`, `job_read_failed`, `estimate_unavailable`, `host_too_old`); `full_quality_pending` (409, `details.retryable: true`) is not final — an earlier try's 1080p render of the draft is being reviewed or has not started yet, so try again later — while `full_quality_unavailable` is final. `CastSwapParams` gains `references` (`CastSwapReference[]`, at most 5): fixed references, each 1–3 images of one thing plus the `line` that names it (`{image}` in the line stands for its first image), sent as given and counted toward the 30 images.

Trends (`client.trends`): `TrendRunRequest` gains `origin` — on `run()`, the client app's slug (e.g. `"tools"`), stored on the run's job as `input_data.origin` so `jobs.list({ origin })` finds it.

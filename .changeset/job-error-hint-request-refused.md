`JobErrorHint` gains `RequestRefusedHint` (`kind: "request-refused"`): the provider refused the request as it was sent, naming a fault of it, so the same request is refused again. Change the input images, the video, the prompt or the settings before running it again. `TrendRun.error.code` can carry the same value, and `input-refused` when the video provider refused the trend's own clip.

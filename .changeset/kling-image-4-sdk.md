`GenerateImageParams.imageSetCount` (2–10): on a model that makes sets (Kling Image 4.0), one job returns a coherent set of that many images, charged for the images returned. `ImageResolution` takes `8K` (Kling Image 4.0's largest size). `GenerateImageParams.referenceCharacters`: on a flat request, which character each reference came from, so Kling Image 4.0 sends a character's views as one named subject.

A new KIE video model family in the catalog: **LTX 2.5 Fast** (`ltx-2.5-fast`) and **LTX 2.5 Pro** (`ltx-2.5-pro`), made by Lightricks. A different model from LTX 2.3 (`ltx-2.3-pro`, `ltx-2.3-fast`), which is unchanged.

- Catalog entries: one id per tier over two provider endpoints, chosen by whether a start frame is connected (image-to-video keeps the frame's shape; text-to-video takes `16:9`, `9:16`, `1:1`, `3:2` or `2:3`). Picture and sound in one pass on every run (feature `audio`; `VIDEO_AUDIO_CAPABILITY` `{ mode: "ambient", alwaysOn: true, defaultOn: true }`, no switch, nothing priced or sent for it). Fast: 6–20 s in 2 s steps at `720p` / `1080p` / `1440p`; Pro: 6 / 8 / 10 s at `720p` / `1080p`. Declared defaults `1080p` (`defaultResolution`, `unlistedResolutionRendersAs`, `PRICING_DEFAULT_RESOLUTION`) and 10 s. Seeded, no end frame, prompts up to 5,000 characters. Listed in both `IMAGE_TO_VIDEO_PROVIDERS` and `TEXT_TO_VIDEO_PROVIDERS`, no `VIDEO_MODE_ALIASES` row.
- New catalog fields: `frameRates` (the frame rates a video model renders, the first its default — LTX 2.5: 24, 25, 48, 50), `longClipLimit` (`{ maxSeconds, resolutions?, frameRates? }`: lengths past `maxSeconds` render only at the other resolutions and frame rates — LTX 2.5 Fast: 10 s at 1440p or 48 / 50 fps) and `noNegativePrompt` (the model takes no negative prompt: `applyVideoNegativePrompt` drops it instead of folding an `Avoid:` line).
- New helpers: `videoFrameRateFor(modelId, fps)` and `videoDurationsAt(modelId, { resolution, fps })` (`@nodaro/shared/model-catalog`), `videoDurationCappedAt(provider, seconds, { resolution, fps })`, `LTX_2_5_PROVIDERS`, `isLtx25Provider()`, `LTX_2_5_DEFAULT_RESOLUTION`, `normalizeLtx25Resolution()` and type `Ltx25Provider` (`@nodaro/shared/models`).
- Credit identifiers: `ltx-2.5-fast:<N>s:<resolution>` and `ltx-2.5-pro:<N>s:<resolution>`. `buildVideoCreditModelIdentifier` never names a row past a model's `longClipLimit` at the resolution it is given; `pricedVideoSelection` and `videoGenerationCreditId` take an optional `fps` and apply the frame-rate half of the limit (read only for a model that declares one, so every other model's identifiers are unchanged). `VIDEO_DURATION_TIERS`, `RESOLUTION_DURATION_PRICING`, `DURATION_PRICED_PROVIDERS` and `VIDEO_VARIABLE_PRICING` (`"duration+resolution"`) gain both ids.
- Catalog field `aspectRatiosTextOnly`: the ratios apply to text-only runs, and a start frame keeps its own shape — `resolveFrameFitAspect` gives no crop target for such a model (LTX 2.5).
- `MODEL_INPUT_ADJUSTMENT_FIELDS` gains `"fps"`, for a frame rate a request named and the model does not render.
- `uiResolutionFill` / `uiDurationFill` return 1080p / 10 s for both ids; `QUALITY_MAP` maps low / mid / high to 720p / 1080p / 1440p (Fast) and 720p / 1080p / 1080p (Pro).

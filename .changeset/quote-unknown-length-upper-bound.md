`videoSfxQuoteCreditId` and `pitchTempoQuoteCreditId`: the price id an estimate names before a run. A known length is the id its run is charged; an unknown length is the most a run can be charged — Video SFX's 300-second row, Pitch & Tempo's 30-minute id — so a quote is never below the charge.

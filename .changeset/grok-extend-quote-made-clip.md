`grokExtendWiredSourceResolution(nodeId, nodes, edges, rerunIds?)` now quotes a Grok Extend from the clip the wired Grok Imagine node already made — the take its task (`kieTaskId`) names, which the run extends — instead of the node's current setting, and from the same fact the charge reads: the resolution that take's job recorded, which the result row carries as `recordedResolution`. `480p` (any case) → the 480p row; anything else, none, or no result naming the task (a result made before results recorded it, or a deleted one) → the 720p row, so a quote is never below the charge. A file's pixel size is never read. A node that has not run yet, or that makes a new clip in the quoted run (`rerunIds`, the nodes that run executes, frozen ones excluded), is quoted at its setting as before. Without `rerunIds` (one node's own price) nothing upstream runs again.

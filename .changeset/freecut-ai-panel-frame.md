Edit with AI in a frame, through the `media` entry. The platform serves the Edit with AI panel at `AI_PANEL_PATH` (`/embed/edit-with-ai`), for a product that embeds the video editor (FreeCut) to frame beside it. The editor takes commands only from the page that frames it, so that page carries the panel's edit requests to the editor and the editor's answers back: `routeAiPanelMessage(event, context)` says where one message goes (or `null` when it is not the panel's), and `createAiPanelRelay({ host, panel, panelOrigin, editor, editorOrigin })` does it until disposed. An answer reaches the panel only for a request the panel made, and an import's buffers are handed over again. The panel and its host speak `NODARO_AI_PANEL_READY`, `NODARO_AI_PANEL_INIT` (`AiPanelInitPayload`: the editor's capabilities, the videos the host can give an address for as `AiPanelVideo`, the video the editor was opened on, and `project`, which the host changes when it starts a fresh project), `NODARO_AI_PANEL_LAYOUT` (`AiPanelLayoutPayload`) and `NODARO_AI_PANEL_CLOSE`; `aiPanelOffered(capabilities)` says whether an editor can be edited by the panel (`AI_PANEL_EDITOR_CAPABILITIES`). The editor's own edit messages are now named here too: `NODARO_GET_TIMELINE`, `NODARO_APPLY_OPS`, `NODARO_UNDO_EDIT`, `NODARO_PLAYBACK`, `NODARO_PRESENCE` and their answers `FREECUT_TIMELINE`, `FREECUT_OPS_RESULT`, `FREECUT_UNDO_RESULT`.

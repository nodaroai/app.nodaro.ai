`PublishedApp.perItemCredits`: credits for each item beyond the creator's saved items of a list input the app's user fills. `PublishedAppDetail.runEstimatedCredits`, `runPerMinuteCredits` and `runPerItemCredits`: the app run alone, the listed price less its Render final part.

Nodaro Video Upscale has two modes: `NODARO_VIDEO_UPSCALE_MODES` (`"transparent"`, `"sharp"`), `NODARO_VIDEO_UPSCALE_DEFAULT_MODE` (`"transparent"`) and `nodaroVideoUpscaleModeOf`, the one reading every lane uses (unset or unknown is transparent). Transparent also takes 720p (`NODARO_VIDEO_UPSCALE_TRANSPARENT_TIERS`, `nodaroVideoUpscaleTiersFor`, `nodaroVideoUpscaleModeTakes`, `NODARO_VIDEO_UPSCALE_MODE_BOX`, `nodaroVideoUpscaleBoxFor`: both modes deliver inside the tier's box, Transparent's 720p box being 1280×720). `videoUpscaleResolutionsFor` and `normalizeVideoUpscaleResolution` take an optional `mode`, so a sharp request for 720p is coerced to 1080p. The catalog entry lists 720p among its resolutions and describes both modes. A request that names no mode now runs transparent. `nodaroVideoUpscaleEffectiveMode(asked, transparentServes)` is the one decision every lane uses: an explicit mode is kept; with no mode, a clip Transparent cannot serve at the chosen tier (or an install that cannot run it) runs Sharp at Sharp's price. `nodaroVideoUpscaleQueuedModeOf` reads a queued or stored job, where no mode means Sharp (a job queued before modes existed).

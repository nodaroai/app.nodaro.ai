`client.trends` (also `@nodaro/sdk/trends`): browse the published trend catalog and run a trend with your own pictures. `list(params?)` (`GET /v1/trends`; `q`, `tag`, `favorites: true`, `locale`, `cursor`, `limit` 1–60) and `runs(params?)` (`GET /v1/trends/runs`; `trend`, `cursor`, `limit`) return `{ data, next }` pages; `get(slug, { locale }?)` returns a `TrendDetail`; `estimate(slug, request)` returns `{ expectedCredits, holdCredits, breakdown }` and spends nothing; `run(slug, request, { idempotencyKey }?)` starts a run (202) and returns `{ jobId }` (the key is sent as the `Idempotency-Key` header); `favorite(slug)` / `unfavorite(slug)` (`PUT` / `DELETE /v1/trends/:slug/favorite`, 204). Types: `TrendCard`, `TrendDetail`, `TrendDetailSlot`, `TrendExample`, `TrendRunRequest`, `TrendRunSlot`, `TrendChips`, `TrendChoice`, `TrendSlotKind`, `TrendResolution`, `TrendEstimate`, `TrendRunOptions`, `TrendRun`, `TrendRunDisplaySlot`, `ListTrendsParams`, `ListTrendRunsParams`, `TrendPage`. Refusals: 400 (`validation_error`, `missing_slot`, `unknown_slot`, `invalid_choice`, `example_out_of_range`, `preview_unavailable`, `invalid_slot_mention`, `prompt_too_long`; slot errors carry `slot`), 401, 404 `not_found`, 502 `engine_error`, 503 `engine_unsupported` / `trend_unavailable`, 503 `not_available` (no trend catalog on this server yet). `estimate` / `run` answer the video engine's refusals with the trend routes' own codes and fixed text, never the engine's message or `issues`: 400 `trend_run_rejected` (or `clip_out_of_range`, `preview_out_of_range`, `video_unreadable`, `unsafe_url`, `raw_reference_token`), 402 as given, 413 `storage_limit_exceeded`, 422 `job_blocked`, 429 `rate_limited`, 503 `engine_unsupported` / `estimate_unavailable`, else 502 `engine_error`. `"runs"` is never a slug: `get` / `estimate` / `run` / `favorite` / `unfavorite` throw a `TypeError` for it before any request. `sessionId` and `projectId` are accepted but not yet applied (trend runs are not filed into sessions or projects yet). Cloud edition only.
